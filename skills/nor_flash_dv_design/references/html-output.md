# HTML 輸出規範

## 使用範本

讀取並複製 `../assets/verification-plan-template.html`，保留視覺風格與互動骨架，再依本次功能替換內容。範本是無產品規格的版型，所有 `{{...}}` 都必須替換。它取材自使用者的 NOR_Flash_DV_Guide_V6.html 閱讀架構，不包含該案例的實測資料。

每個功能使用一個 `article.chapter` 與唯一 id。新增章節時，導覽會由 JavaScript 讀取 `data-title` 建立。同步更新章內圖形、測項與錨點，避免重複 id。單功能時隱藏上一章／下一章按鈕。

## 內容與圖形

- 每章保留概念、執行前說明、產品規則、共通方法、流程總覽、測項、邊界／未定義用法、復原與判讀、待確認與來源。
- 主測項表維持「步驟／做什麼／預期」；需要時增加觀察點，避免一張表塞十幾欄。
- 每個 Flow 的標題說明目的，必要時補「為什麼這樣測」。圖上只放階段與方向，細節留在測項表。
- 依功能產生 SVG 狀態／資料流、記憶體區域、資料前後差異或鎖定範圍圖。圖中文字清楚，箭頭對準節點；複雜流程分圖，不硬塞進固定尺寸。
- 範本總覽採 HTML 卡片與箭頭；SVG 可表達分支與狀態。兩者均不依賴 Mermaid。
- 正驗、反驗可放在同一個功能 Flow；不必強迫四類各自成章。
- 未定義項目列「可能結果／觀察點／要問 Designer」，不得拿範例樣品的行為當新料號預期。
- 沒有實測時標「待審查／未執行」，頁面不放虛構通過率或 PASS 統計。

## 技術要求

- 單檔 HTML，UTF-8、`lang="zh-Hant"`、viewport；CSS、JavaScript、SVG 內嵌。沒有外部字型、CDN、網路請求或建置步驟。
- 章節切換、上一章／下一章及測項連結可用；使用者能直接開檔閱讀。JavaScript 關閉時仍顯示所有章節。
- SVG 提供標題；按鈕可用鍵盤操作，有焦點樣式。不要只靠顏色傳遞結果。
- 窄螢幕讓圖表在各自容器捲動，不讓整個頁面橫向溢出。
- 列印顯示全部章節與參考依據，隱藏導覽、按鈕，使用白底黑字，避免表格被截斷。
- 文件文字與來源需作 HTML escaping；不用 `innerHTML` 注入不可信文件文字。

## 交付檢查

檢查規格來源、圖表／步驟編號、流程分支、前置／復原與實測狀態一致。確認沒有佔位符、錯誤跨章連結、範例產品資訊或程式實作宣稱。

實際開啟檢查桌面與窄螢幕、章節切換、直接錨點跳轉、列印全部章節，以及沒有 JavaScript 時內容仍可讀。不可把靜態結構檢查說成已做瀏覽器檢查。
